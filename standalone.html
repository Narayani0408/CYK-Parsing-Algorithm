Formal Algorithm: CYK(G, w)

Input: A Context-Free Grammar \(G = (V, \Sigma, R, S)\) in Chomsky Normal Form (CNF) and an input string \(w = c_0 c_1 \dots c_{n-1}\) of length \(n\).

  1. Initialize a triangular dynamic programming table \(T[n][n]\), where each entry \(T[i][j]\) is a set of variables initialized to \(\emptyset\).
  2. Base Case (Length 1): For each terminal character \(w[i]\) where \(0 \le i < n\):
    Find all non-terminals \(A\) such that \(A \to w[i] \in R\).
    Add \(A\) to \(T[i][i]\).
  3. Inductive Step (Lengths \(l = 2 \text{ to } n\)):
    For every starting position \(i = 0 \text{ to } n - l\):
      Set ending position \(j = i + l - 1\).
      For every partition point \(k = i \text{ to } j - 1\):
        Check each \(B \in T[i][k]\) and \(C \in T[k+1][j]\).
        If production \(A \to BC \in R\), add \(A\) to \(T[i][j]\).
  4. Membership Check: Check whether the start symbol \(S \in T[0][n-1]\).
  5. If \(S \in T[0][n-1]\), return ACCEPT; otherwise return REJECT.

Pseudocode

CYK(G, w):
  n = length(w)
  let T[n][n] be sets of variables

  // Base Case: length 1
  for i = 0 to n - 1:
    T[i][i] = { A | A → w[i] ∈ G }

  // Substrings of length 2 to n
  for length = 2 to n:
    for i = 0 to n - length:
      j = i + length - 1

      // Try all split points k
      for k = i to j - 1:
        for each production A → BC:
          if B ∈ T[i][k] and C ∈ T[k+1][j]:
            T[i][j].add(A)

  return S ∈ T[0][n - 1]

Complexity Analysis & Dynamic Programming Rationale

Time Complexity
O(n³ × |P|)

Where \(n\) is the input string length and \(|P|\) is the total number of grammar productions.

Space Complexity
O(n² × |V|)

Where \(n\) is string length and \(|V|\) is the total number of non-terminal variables.

Why \(O(n^3 \cdot |P|)\)? The algorithm uses three nested loops: The outer loop iterates over substring lengths \(l \in [2 \dots n]\) (\(O(n)\) iterations). The middle loop iterates over start positions \(i \in [0 \dots n-l]\) (\(O(n)\) iterations). The innermost loop tests all partition points \(k \in [i \dots j-1]\) (\(O(n)\) iterations). For each split, evaluating whether candidate pairs \(BC\) match binary rules takes at most \(O(|P|)\) operations. Thus, the overall running time is strictly bounded by \(O(n^3 \cdot |P|)\).

Dynamic Programming Foundation: A naive backtracking or top-down recursive parser exhibits exponential time complexity \(O(2^n)\) due to repeated derivation of identical subproblems. CYK achieves polynomial time efficiency by exploiting:

  • Optimal Substructure: A parse tree for string \(w[i..j]\) with root \(A \to BC\) is composed of valid parse subtrees for \(w[i..k]\) rooted at \(B\) and \(w[k+1..j]\) rooted at \(C\).
  • Overlapping Subproblems: Substrings of length \(k\) are repeatedly required when evaluating multiple larger substrings of length \(> k\). CYK tabulates results in a triangular matrix \(T[n][n]\), calculating each subproblem exactly once.
